# Mia's USA Paper Journey

一个原创的 3D 纸艺旅行叙事网站：可爱小女孩 Mia 从旧金山出发，沿 66 号公路穿过美国，抵达纽约，再飞往夏威夷。

## 技术栈
- Vite
- Three.js
- 原创 SVG 纸艺资产
- CatmullRomCurve3 滚轮镜头轨迹
- Raycaster 3D Hover

## 场景
1. San Francisco — Golden Gate / Cable Car
2. Route 66 — Desert / Road Sign / Cactus
3. New York City — Skyline / Liberty / Taxi
4. Hawaii — Palm / Surfboard / Ocean

## 运行
```bash
npm install
npm run dev
```

## 构建
```bash
npm run build
```

所有 `public/assets` 下的角色与场景 SVG 均为本项目原创设计资产。
