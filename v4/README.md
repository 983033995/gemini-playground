# Mia Across America — V4 Production

This branch archives the V4 production baseline for the scroll-driven Three.js travel world.

## What is here
- `PRODUCTION_PLAN.md`: World/asset production order and NYC vertical-slice acceptance criteria.
- `asset-manifest.json`: runtime and production manifest.
- `reference/asset-direction-board.webp`: visual direction board.
- `reference/production-roadmap.webp`: production pipeline board.
- `reference/crops/`: cropped reference categories for character, poses, vehicles, NYC, subway, Times Square, props, UI and atmosphere.

## Important
Everything under `reference/` is **art-direction/reference material**, not final web-ready production assets.
Final production assets are generated independently, identity-locked, QA'd, then compiled for Three.js/Oil Motion.
