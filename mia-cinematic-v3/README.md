# Mia Across America — Cinematic V3

A self-contained, scroll-directed 2.5D illustrated travel film.

Journey: NYC walk → subway → Times Square → taxi / Route 66 → Grand Canyon → San Francisco cable car → Golden Gate.

- No external visual assets.
- Character, vehicles and landmarks are original inline SVG illustrations.
- `standalone.html` is deployment-ready.
- `index.html` + `style.css` + `app.js` are the editable source files.
